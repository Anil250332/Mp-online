# 🛡️ Development & Behavior Guidelines

1. **Memory First**: Always read `memory.md` and `project.md` before starting any task.
2. **Post-Task Logging**: Every completed action must be logged in `memory.md` with:
   - 1. Kya kiya (What was done)
   - 2. Kyu kiya (Why it was done)
   - 3. Is se hua kya (Impact / Result)
   - 4. Kya koi aur optimize tareeka hai (Optimization & Alternatives)
3. **Controlled Scope**: Do not create or edit unrequested files. Avoid unnecessary refactoring.
4. **Technology Constraints**: Node.js + Express.js + MySQL (Backend), React + TypeScript + Vite + Tailwind CSS (Frontend).
5. **Security & Financial Integrity**: Enforce atomic SQL transactions for all wallet operations. Do not store sensitive govt portal credentials.
